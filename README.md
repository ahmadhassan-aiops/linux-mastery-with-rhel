## 🎯 About this course

Practical Linux notes for anyone heading into DevOps, cloud, security or MLOps work, where almost every server runs Linux. The course starts with distribution-independent basics, then goes deep into RHEL, the standard in enterprise data centres and the base of the RHCSA exam. Every topic explains the concept in plain English, shows the commands, and ends with practice questions and answers.

## 🚀 How to use it

1. **Get a lab machine.** Install [Rocky Linux](https://rockylinux.org), [AlmaLinux](https://almalinux.org) or [CentOS Stream](https://www.centos.org) (free RHEL rebuilds) in VirtualBox or VMware, or get a free [Red Hat Developer subscription](https://developers.redhat.com/register) for real RHEL. A cloud VM works too.
2. **Take snapshots** before the disk, LVM, fstab, firewall and boot topics, so a mistake costs a click instead of a reinstall.
3. **Follow the folders in order:** Linux Basics, RHEL Fundamentals, RHEL Networking and Administration, then RHEL Services.
4. **Type every command yourself** and try the questions at the end of each topic before opening the answers.
5. For the services labs, create two VMs (a server and a client) on the same host-only or NAT network.

> 💡 Commands are written for RHEL 8 and 9. Where RHEL 6 or 7 did things differently, both ways are shown, because older servers are still common in production.
