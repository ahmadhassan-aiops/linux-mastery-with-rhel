# 04. The vi Editor

`vi` (on RHEL it is usually **vim**, "vi improved") is installed on every Linux server, so it is the editor you can always count on.

## The Three Modes

| Mode | How to enter | Used for |
|---|---|---|
| **Command (normal)** | `Esc` | Moving, deleting, copying, pasting |
| **Insert** | `i`, `a` or `o` | Typing text |
| **Last-line (ex)** | `:` from command mode | Saving, quitting, searching, settings |

Open a file with `vi filename`. You start in **command** mode.

## Essential Commands

**Entering insert mode**

| Key | Inserts |
|---|---|
| `i` | Before the cursor |
| `a` | After the cursor |
| `o` / `O` | On a new line below / above |

**Saving and quitting**

| Command | Action |
|---|---|
| `:w` | Save |
| `:q` | Quit (only if nothing changed) |
| `:wq` or `:x` | Save and quit |
| `:q!` | Quit and discard changes |
| `:w!` / `:wq!` | Force the write (for example, on a file you own but which is read-only) |

**Editing in command mode**

| Key | Action |
|---|---|
| `dd` / `5dd` | Delete (cut) the line / 5 lines |
| `yy` / `5yy` | Copy (yank) the line / 5 lines |
| `p` | Paste below |
| `u` / `Ctrl+R` | Undo / redo |
| `x` | Delete one character |
| `gg` / `G` | First / last line |

## Last-Line Commands from the Notes

| Command | Action |
|---|---|
| `:set nu` / `:set nonu` | Show / hide line numbers |
| `:20` | Jump to line 20 |
| `/word` | Search forward for `word`; `n` for the next match, `N` for the previous one |
| `:%s/old/new/g` | Replace every `old` with `new` |
| `:split` / `:vsplit` | Split the window horizontally / vertically |
| `:split /etc/hosts` | Open another file in a split |
| `Ctrl+W` then `w` | Move to the next split window |
| `:X` | Encrypt the file with a password (vim only). To remove it, run `:X` again, press Enter twice at the empty prompt, then `:w` |

> 💡 **nano** is a simpler alternative (`nano file`); its shortcuts are listed at the bottom of the screen.

## Practice

Open `/tmp/practice.txt` in vi, then:

1. Type three lines of text and save.
2. Turn on line numbers, go to line 2, copy it and paste it at the end.
3. Replace every `the` with `THE`, then quit **without** saving.

<details>
<summary>Solution</summary>

```text
vi /tmp/practice.txt
i  (type three lines)  Esc  :w
:set nu   :2   yy   G   p
:%s/the/THE/g
:q!
```
</details>
