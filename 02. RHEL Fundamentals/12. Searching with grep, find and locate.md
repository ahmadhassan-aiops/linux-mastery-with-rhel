# 12. Searching with grep, find and locate

## The Pipe, Again

`|` sends one command's output into the next command:

```bash
ls /etc | wc -l          # how many entries in /etc?
ls -R /etc | less        # scroll line by line (arrows), q to quit
ls -R /etc | more        # page by page (Space)
```

## grep: Search Inside Text

`grep` finds lines containing a word or pattern, like Ctrl+F for the command line.

```bash
grep root /etc/passwd                     # lines containing "root"
grep --color 'root' /etc/passwd           # highlight the match
grep -i 'error' /var/log/messages         # ignore case
grep -n 'Listen' /etc/httpd/conf/httpd.conf  # show line numbers
grep -A2 'ServerName' httpd.conf          # also 2 lines After each match
grep -B2 'ServerName' httpd.conf          # also 2 lines Before
grep -C2 'ServerName' httpd.conf          # 2 lines of Context on both sides
grep -v '^#' /etc/fstab                   # lines NOT starting with # (hide comments)
grep -r 'PermitRootLogin' /etc/ssh/       # search every file in a directory
grep -c 'Failed' /var/log/secure          # count matching lines
ls /etc | grep -i host                    # filter another command's output
```

## find: Search for Files

`find` walks the directory tree and matches files by name, owner, size, age, permissions and more.

```bash
find /etc -iname "*.conf"          # by name, ignoring case
find / -iname "*.txt"              # anywhere on the system
find . -iname "*.txt"              # in the current directory
find .. -iname "*.txt"             # in the parent directory
find / -user ahmad                 # owned by ahmad
find / -size +100M                 # bigger than 100 MB
find /var/log -mtime +10           # modified more than 10 days ago
find / -type d -name backup        # directories only (-type f for files)
find / -perm 777                   # with permissions exactly 777
```

### Acting on the Results: -exec

```bash
find /opt -user ahmad -exec rm -rf {} \;
```

| Part | Meaning |
|---|---|
| `-exec` | Run a command on every result |
| `{}` | Replaced by each file found |
| `\;` | Ends the command. The backslash stops the shell from treating `;` itself |

More examples:

```bash
find / -perm 777 -exec chmod 755 {} \;             # fix world-writable files
find /var/log/httpd -mtime +10 -exec rm -f {} \;   # delete logs older than 10 days
find /data -name "*.tmp" | xargs rm -f             # the same idea with xargs (faster)
```

> ⚠️ Run the `find` part alone first and read the list before adding `-exec rm`. Reference: https://www.tecmint.com/35-practical-examples-of-linux-find-command/

## locate: Instant Search from a Database

`locate` doesn't walk the disk. It looks names up in a database, so it answers instantly.

```bash
dnf install mlocate      # RHEL 8 (on RHEL 9 the package is plocate)
updatedb                 # build or refresh the database
locate sshd_config
```

| | `find` | `locate` |
|---|---|---|
| Speed | Slow on big trees | Instant |
| Up to date | Always: it reads the disk | Only as fresh as the last `updatedb` (refreshed daily by a timer) |
| Criteria | Name, owner, size, age, permissions | Name only |
| Database | None | `/var/lib/mlocate/mlocate.db` (RHEL 8), `/var/lib/plocate/plocate.db` (RHEL 9) |

A file created five minutes ago won't show up in `locate` until you run `updatedb`.

## Questions

1. Show all active (non-comment) lines of `/etc/ssh/sshd_config`.
2. Find every file over 1 GB on the system, hiding "Permission denied" errors.
3. Delete every `.log` file under `/opt/app` older than 30 days.

<details>
<summary>Answers</summary>

1. `grep -v '^#' /etc/ssh/sshd_config | grep -v '^$'`
2. `find / -type f -size +1G 2>/dev/null`
3. `find /opt/app -name "*.log" -mtime +30 -exec rm -f {} \;`
</details>
