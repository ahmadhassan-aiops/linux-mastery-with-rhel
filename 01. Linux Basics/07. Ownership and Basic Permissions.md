# 07. Ownership and Basic Permissions

Every file has an **owner** (a user), a **group**, and a set of **permissions** for three classes of people: the owner (`u`), the group (`g`) and everyone else (`o`).

## Reading a Long Listing

Recorded on the lab machine:

```text
[root@localhost Documents]# ls -l sample_ownership_understanding_file.txt
-rw-r--r--. 1 root root 0 Apr 11 13:17 sample_ownership_understanding_file.txt
```

| # | Entry | Meaning |
|---|---|---|
| 1 | `-rw-r--r--.` | File type and permissions (the final `.` means an SELinux context is set) |
| 2 | `1` | Hard link count |
| 3 | `root` | Owner (user) |
| 4 | `root` | Group |
| 5 | `0` | Size in bytes |
| 6 | `Apr 11 13:17` | Last modified |
| 7 | `sample_ownership_understanding_file.txt` | File name |

The permission string splits into the type and three triplets:

```text
 -    rw-    r--    r--
type  user  group  others
```

| Letter | On a file | On a directory |
|---|---|---|
| `r` read | View the contents | List the names inside |
| `w` write | Change the contents | Create, delete and rename files inside |
| `x` execute | Run it as a program | Enter it with `cd` |

## Changing the Owner: chown

As root (recorded):

```text
[root@localhost Documents]# chown ahmad sample_ownership_understanding_file.txt
[root@localhost Documents]# ls -l sample_ownership_understanding_file.txt
-rw-r--r--. 1 ahmad root 0 Apr 11 13:17 sample_ownership_understanding_file.txt
```

As a normal user with sudo rights (recorded):

```text
[ahmad@localhost Documents]$ sudo chown -R sara sample_ownership_understanding_file.txt
[ahmad@localhost Documents]$ ls -l sample_ownership_understanding_file.txt
-rw-r--r--. 1 sara root 0 Apr 11 13:17 sample_ownership_understanding_file.txt
```

`-R` (recursive) matters for directories: it changes everything inside too.

## Changing the Group: chgrp

```text
[root@localhost Documents]# chgrp ahmad sample_ownership_understanding_file.txt
[root@localhost Documents]# ls -l sample_ownership_understanding_file.txt
-rw-r--r--. 1 sara ahmad 0 Apr 11 13:17 sample_ownership_understanding_file.txt
```

```text
[ahmad@localhost Documents]$ sudo chgrp -R sara sample_ownership_understanding_file.txt
[ahmad@localhost Documents]$ ls -l sample_ownership_understanding_file.txt
-rw-r--r--. 1 sara sara 0 Apr 11 13:17 sample_ownership_understanding_file.txt
```

> 💡 `chown user:group file` changes both at once, for example `chown ahmad:devops report.txt`.

## Changing Permissions: chmod

**Symbolic mode:** who (`u`, `g`, `o`, `a` for all), then `+`, `-` or `=`, then the permissions.

```bash
chmod u+x script.sh            # owner may execute
chmod g+x script.sh            # group may execute
chmod o+x script.sh            # everyone else may execute
chmod u+x,g+x,o+x script.sh    # all three (same as chmod a+x)
chmod u-x,g-x,o-x script.sh    # take execute away from all three
chmod g=rw script.sh           # group gets exactly read and write
```

**Numeric (octal) mode:** add `r=4`, `w=2`, `x=1` for each class. RHEL Fundamentals topic 05 goes deeper.

```bash
chmod 755 script.sh   # rwxr-xr-x
chmod 644 notes.txt   # rw-r--r--
chmod 600 id_rsa      # rw------- (private keys)
```

## Practice

1. Create `report.txt`, make `ahmad` the owner and `devops` the group with one command.
2. Allow the owner to read and write, the group to read, and others nothing. Write it both ways.

touch report.txt
chown ahmad:devops report.txt
chmod u=rw,g=r,o= report.txt
