# 08. Networking, Disks, Processes and Packages at a Glance

A first tour of the everyday admin commands. Each area gets its own in-depth topics in the RHEL folders.

## Network

| Command | Shows |
|---|---|
| `ip a` | Network interfaces and their IP addresses |
| `ip route` | The routing table, including the **default gateway** |
| `ifconfig` | The older way to see interfaces (install `net-tools` if it is missing) |
| `ping -c 4 google.com` | Whether you can reach a host |
| `dhclient` | Request an IP address from a DHCP server (on older systems) |

```bash
sudo dnf install net-tools    # RHEL, Rocky, Alma (yum on older releases)
sudo apt install net-tools    # Debian, Ubuntu
```

## Disks and File Systems

| Command | Shows |
|---|---|
| `df` | Free and used space on each mounted file system |
| `df -h` | The same in KB, MB and GB |
| `df -Th` | Also the file system type (xfs, ext4) |
| `du -sh /var` | The total size of one directory |
| `du -h /var` | The size of everything inside it |
| `lsblk` | Disks and partitions as a tree |
| `umount /media/USBDRIVE` | Detach a mounted device (note: `umount`, not "unmount") |
| `umount -l /media/USBDRIVE` | Detach it as soon as it is no longer busy |

## Processes

| Command | Shows |
|---|---|
| `ps` | Processes in your current terminal |
| `ps -e` | Every process |
| `ps -el` | Every process, long format |
| `ps -ef` | Every process, full format with start time and command |
| `top` | Live CPU, memory and process usage (`q` to quit) |
| `kill 1234` | Ask process 1234 to stop |

## Software Packages

| Distribution | Install a file | Install from repositories | Remove |
|---|---|---|---|
| RHEL family | `rpm -ivh pkg.rpm` | `dnf install nginx` (or `yum`) | `dnf remove nginx`, `rpm -e nginx` |
| Debian family | `dpkg -i pkg.deb` | `apt install nginx` | `apt remove nginx`, `dpkg -r nginx` |

> 💡 Prefer `dnf`/`apt` over `rpm`/`dpkg`: they download dependencies for you. Note that `rpm -e` and `dpkg -r` take the **package name**, not the file name.

## Handy Extras

```bash
date              # current date and time
cal               # this month's calendar
uptime            # how long the system has been running, and its load
whoami            # your user name
hostname          # the machine's name
history           # your previous commands
clear             # clear the screen
```
