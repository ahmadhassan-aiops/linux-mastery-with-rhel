# 05. Redirection, Pipes and Expansion

Two Bash features turn simple commands into powerful tools: **redirection** sends output into files, and **pipes** send one command's output into another command.

## Redirection

| Operator | Effect | Example |
|---|---|---|
| `>` | Write output to a file, **replacing** its contents (creates the file if needed) | `ls > list.txt` |
| `>>` | **Append** output to the end of a file | `date >> log.txt` |
| `2>` | Write **errors** to a file | `find / -name x 2> errors.txt` |
| `2>/dev/null` | Throw errors away | `find / -name x 2>/dev/null` |
| `&>` | Write output and errors to the same file | `cmd &> all.txt` |
| `<` | Read input from a file | `wc -l < list.txt` |

```bash
ls -l /usr/bin/ > ls-output.txt     # overwrite
ls -l /usr/bin/ >> ls-output.txt    # add to the end
```

## Pipes

The pipe `|` passes the output of the command on its left as input to the command on its right.

```bash
ls /usr/bin | wc -l                   # how many programs are installed?
ls /usr/bin | sort | less             # sorted, scrollable
ls /usr/bin | sort | uniq | less      # sorted, without duplicates
ls /usr/bin | grep zip                # only names containing "zip"
cat /etc/passwd | grep ahmad          # search inside a file (grep ahmad /etc/passwd also works)
```

| Filter | Does |
|---|---|
| `sort` | Sort lines alphabetically (`-n` numerically, `-r` reversed) |
| `uniq` | Remove repeated adjacent lines (so `sort` first) |
| `grep word` | Keep lines that contain `word` (`-i` ignores case) |
| `wc -l` | Count lines |
| `head`, `tail` | Keep the first or last lines |
| `less`, `more` | Page through the output |

## Expansion

Before running a command, Bash **expands** special characters.

| You type | Bash turns it into |
|---|---|
| `echo *` | Every file name in the current directory |
| `echo p*` | Every name starting with `p` |
| `echo .[!.]*` | Hidden files (names starting with one dot) |
| `touch file{1..5}` | `file1 file2 file3 file4 file5` |
| `echo $((2 + 2))` | `4` (arithmetic) |
| `echo ~` | Your home directory |
| `echo $USER` | The value of a variable |
| `!!` | The previous command (`sudo !!` reruns it as root) |
| `!foo` | The most recent command that started with `foo` |

Quotes control expansion: double quotes `"..."` still expand variables, single quotes `'...'` keep everything literally.

```bash
echo "Home: $HOME"    # Home: /home/ahmad
echo 'Home: $HOME'    # Home: $HOME
```

## Practice

1. Save a sorted list of everything in `/etc` to `etc.txt`, then append today's date to the same file.
2. How many entries in `/usr/bin` contain the word `python`?
3. Create the files `log1` to `log10` with one command.

<details>
<summary>Solution</summary>

```bash
ls /etc | sort > etc.txt && date >> etc.txt
ls /usr/bin | grep python | wc -l
touch log{1..10}
```
</details>
