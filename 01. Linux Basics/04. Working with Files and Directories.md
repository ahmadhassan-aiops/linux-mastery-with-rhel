# 04. Working with Files and Directories

## Creating

```bash
touch data.txt               # create an empty file (or update its timestamp)
mkdir projects               # create a directory
mkdir dir1 dir2 dir3         # several at once
mkdir -p a/b/c               # create the whole path, parents included
```

## Copying, Moving and Renaming

```bash
cp file1 file2               # copy a file
cp -r source_dir dest_dir    # copy a directory and everything in it
mv oldname newname           # rename
mv file.txt /tmp/            # move
```

## Deleting

```bash
rm file1 file2 file3         # delete files
rmdir emptydir               # delete an EMPTY directory
rm -r dir                    # delete a directory and its contents
rm -i file                   # ask before each deletion
```

> ⚠️ Linux has no recycle bin on the command line. `rm` is permanent, and `rm -rf` never asks. Double-check the path, especially when you are root.

## Viewing Files

| Command | Use |
|---|---|
| `cat file` | Print the whole file |
| `cat -n file` | With line numbers (`-b` numbers only non-blank lines) |
| `head file` / `head -n 5 file` | First 10 / first 5 lines |
| `tail file` / `tail -n 5 file` | Last 10 / last 5 lines |
| `tail -f /var/log/messages` | Follow a log live as new lines arrive (Ctrl+C to stop) |
| `less file` | Scroll freely with the arrow keys; `/word` to search, `q` to quit |
| `more file` | Page by page (Space for the next page) |
| `wc file` | Lines, words and characters (`wc -l` for lines only) |
| `file name` | What kind of file it is (text, image, binary) |

## A First Look at vi

`vi` (and its improved version `vim`) is available on every Linux server. Topic 04 of RHEL Fundamentals covers it properly; for now, know how to get out:

| Keys | Action |
|---|---|
| `vi notes.txt` | Open (or create) a file |
| `i` | Start typing (insert mode) |
| `Esc` then `:wq` | Save and quit |
| `Esc` then `:q!` | Quit without saving |

## Practice

1. Create `~/lab`, and inside it the files `a.txt`, `b.txt` and the directory `old`.
2. Copy `a.txt` to `old/a-backup.txt`, then rename `b.txt` to `c.txt`.
3. Put the output of `ls -l /etc` into `a.txt` and count its lines.
4. Delete the whole `~/lab` directory with one command.

<details>
<summary>Solution</summary>

```bash
mkdir -p ~/lab/old && cd ~/lab && touch a.txt b.txt
cp a.txt old/a-backup.txt
mv b.txt c.txt
ls -l /etc > a.txt
wc -l a.txt
cd ~ && rm -r ~/lab
```
</details>
