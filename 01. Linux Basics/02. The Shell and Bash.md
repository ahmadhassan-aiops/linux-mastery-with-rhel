# 02. The Shell and Bash

You never talk to the kernel directly. You talk to a **shell**: a program that reads your commands, runs them and shows the result. Both the graphical desktop and the command line are shells in this sense, but in Linux "shell" usually means the command-line one.

## Common Shells

| Shell | Program | Notes |
|---|---|---|
| **Bourne shell** | `sh` | The original Unix shell (1977) |
| **Bash** | `bash` | "Bourne Again SHell" by Brian Fox for the GNU project (1989). The default on RHEL and most distributions |
| **Z shell** | `zsh` | Bash-compatible with extra features; the default on macOS |
| **C shell** | `csh`, `tcsh` | C-like syntax, rare today |
| **Fish** | `fish` | Friendly, with suggestions as you type |

Check which shells are installed and which one you are using:

```bash
cat /etc/shells     # installed login shells
echo $SHELL         # your login shell
echo $0             # the shell you are in right now
```

## Reading the Prompt

```text
[ahmad@localhost ~]$
  │      │       │ └─ $ for a normal user, # for root
  │      │       └─── current directory (~ means your home)
  │      └─────────── host name
  └────────────────── user name
```

## Keyboard Shortcuts That Save Hours

Bash uses the **readline** library, which gives you these shortcuts.

**Moving the cursor**

| Keys | Action |
|---|---|
| `Ctrl+A` / `Ctrl+E` | Jump to the start / end of the line |
| `Ctrl+F` / `Ctrl+B` | One character forward / back (like the arrow keys) |
| `Alt+F` / `Alt+B` | One word forward / back |
| `Ctrl+L` | Clear the screen (same as `clear`) |

**Editing text**

| Keys | Action |
|---|---|
| `Ctrl+D` | Delete the character under the cursor (on an empty line, it logs out) |
| `Ctrl+T` / `Alt+T` | Swap two characters / two words |
| `Alt+L` / `Alt+U` | Lowercase / uppercase from the cursor to the end of the word |

**Cutting and pasting** (readline calls them *kill* and *yank*)

| Keys | Action |
|---|---|
| `Ctrl+K` | Cut from the cursor to the end of the line |
| `Ctrl+U` | Cut from the cursor to the start of the line |
| `Alt+D` | Cut to the end of the current word |
| `Alt+Backspace` | Cut to the start of the current word |
| `Ctrl+Y` | Paste the last cut text |

**History and control**

| Keys | Action |
|---|---|
| `↑` / `↓` | Previous / next command |
| `Ctrl+R` | Search the history as you type |
| `Tab` | Complete a command or file name (press twice to list options) |
| `Ctrl+C` | Stop the running command |
| `Ctrl+Z` | Pause the running command (resume with `fg` or `bg`) |

## Getting Help

```bash
man ls          # the full manual page (q to quit, /word to search)
ls --help       # a short summary of options
apropos ext3    # search all manual pages for a keyword
type cd         # is it a built-in, an alias or a program?
which python3   # where a program lives on disk
```
