# 05. Installing Software with RPM

## Four Ways to Install Software on RHEL

| Method | Notes |
|---|---|
| **RPM** | Install a downloaded `.rpm` file by hand. No automatic dependencies |
| **YUM / DNF** | Download and install from repositories, with dependencies (still uses RPM underneath) |
| **Source code** | Compile a tarball yourself for full customization (topic 07) |
| **SRPM** | Rebuild a source RPM into a binary package |

Windows `.exe` programs don't run natively. Tools such as **Wine** and **CrossOver** can run some of them, which is fine for experiments but not for production.

## Package Formats

| Format | Distributions | Low-level tool | High-level tool |
|---|---|---|---|
| `.rpm` | RHEL, Rocky, Alma, Fedora, SUSE | `rpm` | `dnf` / `yum` |
| `.deb` | Debian, Ubuntu | `dpkg` | `apt` |

## Installing, Upgrading and Removing

```bash
rpm -ivh package.rpm              # install: i=install, v=verbose, h=progress bar
rpm -Uvh package-2.0.rpm          # upgrade (installs it if it isn't there yet)
rpm -e package                    # erase (remove): give the package NAME, not the file
rpm -ivh --force package.rpm      # reinstall over an existing copy
rpm -ivh --nodeps package.rpm     # skip the dependency check (dangerous, see below)
```

> ⚠️ `--nodeps` installs a package even though its dependencies are missing, so it may not work. Use it only when you are sure the missing pieces are optional (for example, documentation). Installing with `dnf` avoids the problem entirely.

## Querying Packages

| Command | Answers |
|---|---|
| `rpm -qa` | Every installed package |
| `rpm -qa \| grep httpd` | Is `httpd` installed? |
| `rpm -q httpd` | The installed version |
| `rpm -qi httpd` | Information: version, vendor, size, description |
| `rpm -ql httpd` | Every file the package installed |
| `rpm -ql httpd \| wc -l` | How many files |
| `rpm -qc httpd` | Only its configuration files |
| `rpm -qf /etc/httpd/conf/httpd.conf` | Which package owns this file |
| `rpm -qlp package.rpm` | Files inside a package **file**, before installing it |
| `rpm -qR httpd` | What `httpd` requires |
| `rpm -q --whatrequires httpd` | Which installed packages depend on `httpd` |
| `rpm -q --whatprovides webserver` | Which package provides a capability |
| `rpm -V httpd` | Verify: which installed files have changed |

These queries read RPM's own database in `/var/lib/rpm/`. If it gets corrupted, rebuild it:

```bash
rpm --rebuilddb
```

## Getting RPM Files

Download packages from official sources: your distribution's repositories (`dnf download httpd`), the vendor's website, or trusted repositories such as EPEL.

```bash
wget https://example.com/path/package.rpm
curl -O https://example.com/path/package.rpm
```

Both `wget` and `curl` are command-line downloaders.

> 🔐 Third-party RPM search sites exist, but a package from an unknown source runs as root during installation. Check its signature with `rpm -K package.rpm` before installing.

## Remote Access Tools

| From Linux to | Tool |
|---|---|
| Windows (GUI) | `rdesktop` or `xfreerdp` (RDP) |
| Linux (command line) | `ssh` |
| Linux (GUI) | VNC: `vncserver` on the server, `vncviewer` on the client |

## Questions

1. Which package installed the file `/usr/bin/ssh`?
2. How do you list the configuration files of `vsftpd`?
3. `rpm -e httpd` fails with "is needed by". What does that mean?

<details>
<summary>Answers</summary>

1. `rpm -qf /usr/bin/ssh` (it is `openssh-clients`).
2. `rpm -qc vsftpd`.
3. Other installed packages depend on `httpd`. Check them with `rpm -q --whatrequires httpd`, or remove everything together with `dnf remove httpd`.
</details>
