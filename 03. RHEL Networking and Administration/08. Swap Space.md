# 08. Swap Space

**Swap** is disk space the kernel uses as an overflow for RAM. It can be a dedicated **partition** or a **swap file**. It isn't a program, and it stores memory pages, not files like `/home` or `/var`.

## What Swapping Does

When RAM fills up, the kernel moves **inactive** memory pages (an idle program, a background tab) to swap, freeing RAM for active work. When those pages are needed again, they come back into RAM. This lets the system keep running instead of crashing or killing processes.

- **Active** work, such as a playing video, stays in RAM: swapping it would make it stutter.
- Disk is thousands of times slower than RAM, so heavy constant swapping ("thrashing") means the server needs more memory.
- Swap is optional, but recommended: it is a safety net for unexpected memory spikes.

## How Much Swap?

The old rule "swap = 2 × RAM" made sense when RAM was small. Red Hat's current guidance for RHEL 9:

| RAM | Recommended swap | With hibernation |
|---|---|---|
| 2 GB or less | 2 × RAM | 3 × RAM |
| 2 to 8 GB | Equal to RAM | 2 × RAM |
| 8 to 64 GB | At least 4 GB | 1.5 × RAM |
| Over 64 GB | At least 4 GB | Not recommended |

Even a server with hundreds of GB of RAM usually keeps a few GB of swap as a safety net.

## Check Swap

```bash
free -m             # the Swap line: total, used, free
swapon --show       # which partitions or files are used as swap (older: swapon -s)
cat /proc/swaps
```

### Swap Used by One Process

```bash
grep VmSwap /proc/$(pidof -s firefox)/status
```

### Swap Used by Every Process

```bash
for f in /proc/[0-9]*/status; do
  awk '/^Name:/{n=$2} /^VmSwap:/{print $2, "kB", n}' "$f"
done 2>/dev/null | sort -rn | head
```

The loop reads each process's `status` file, prints its swap usage and name, then sorts the largest first.

## Add a Swap Partition

```bash
fdisk /dev/sdb            # n (new), size e.g. +1G, then t and type 82 (Linux swap) on MBR
                          # or type 19 / "Linux swap" on GPT; then w
partprobe /dev/sdb
mkswap /dev/sdb1          # format it as swap
swapon /dev/sdb1          # use it now
blkid /dev/sdb1           # get its UUID
```

Add it to `/etc/fstab` so it's used after reboots:

```text
UUID=<uuid-from-blkid>   none   swap   defaults   0 0
```

Test the fstab entry:

```bash
swapoff -a && swapon -a
swapon --show
```

## Add a Swap File (No Partitioning)

```bash
dd if=/dev/zero of=/swapfile bs=1M count=1024   # a 1 GB file (fallocate -l 1G also works on ext4)
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo '/swapfile none swap defaults 0 0' >> /etc/fstab
```

To grow swap, add another partition or file, or extend a swap logical volume (topic 09) and run `mkswap` on it again.

## Questions

1. A server with 16 GB of RAM needs swap. How much do you give it?
2. `free -m` shows swap used at 100% and the server is crawling. What does that tell you?

<details>
<summary>Answers</summary>

1. At least 4 GB (following Red Hat's guidance for 8 to 64 GB of RAM).
2. Memory is exhausted and the system is thrashing. Find the memory-hungry process (`top`, sort with `M`) and add RAM or fix the application; more swap only hides the problem.
</details>
